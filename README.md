# Gesture System Controller

Control system volume and screen brightness using hand gestures and a webcam.

## Features

- Hand landmark tracking with MediaPipe
- Gesture-based volume control
- Gesture-based brightness control
- Modular Python architecture
- Linux support with PipeWire and brightnessctl

## Tech Stack

- Python
- OpenCV
- MediaPipe Tasks
- NumPy
- PipeWire / WirePlumber (`wpctl`)
- brightnessctl
